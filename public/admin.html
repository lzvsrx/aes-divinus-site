Como tratar uma contribuição

  1. Leia a proposta e procure assuntos semelhantes antes de classificar.
  2. Peça contexto ou passos para reproduzir se faltar informação.
  3. Responda com a decisão e os motivos. Uma ideia aceita ainda pode precisar de planejamento.
  4. Encerre quando resolvida ou sem continuidade, explicando o resultado. Não use o fechamento como indicação automática de que algo foi implementado.

O site não pede senha nem token. Use os controles do GitHub com a sua conta para administrar.
